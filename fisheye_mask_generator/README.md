# Fisheye Mask Generator

A Python application to generate segmentation masks for moving objects (people, vehicles, animals, etc.) in dual fisheye images (185° FOV) from GoPro Max footage.

## Overview

This tool is designed to work with fisheye image pairs generated by `max2sphere.py` from GoPro Max dual-lens frames. The 185° FOV fisheye images cover the full sphere when combined.

### Workflow

1. **Load fisheye pair** - Load front and back fisheye images (185° FOV equidistant projection)
2. **Convert to equirectangular** - Combine both fisheyes into a 360° equirectangular image
3. **Extract perspective views** - Create multiple overlapping perspective views from the equirectangular
4. **Run YOLO segmentation** - Detect and segment objects in each perspective view
5. **Project back to equirectangular** - Map detected masks back to equirectangular coordinates
6. **Stitch masks** - Combine all perspective masks into a coherent equirectangular mask
7. **Convert to fisheye** - Transform the mask back to front and back fisheye format
8. **Save masks** - Output `*_mask.jpg/png` files matching the original fisheye names

### Input Image Naming

The tool auto-detects fisheye pairs based on naming conventions:

- `frame0001_fisheye_front.jpg` ↔ `frame0001_fisheye_back.jpg`
- `image_front.png` ↔ `image_back.png`
- `lens0_0001.jpg` ↔ `lens1_0001.jpg`
- `front_image.jpg` ↔ `back_image.jpg`

### Output Masks

Masks are saved with `_mask` suffix:
- `frame0001_fisheye_front.jpg` → `frame0001_fisheye_front_mask.jpg`
- `frame0001_fisheye_back.jpg` → `frame0001_fisheye_back_mask.jpg`

## Usage

### GUI Application

```bash
python main.py
```

Features:
- Load fisheye image pairs (front + back)
- Preview the combined 360° equirectangular image
- Configure detection settings (number of views, model, confidence threshold)
- Select which object classes to detect (person, bicycle, car, etc.)
- View fisheye inputs, 360° preview, masks, overlay, and perspective views
- Batch process entire folders of fisheye pairs
- Save mask pairs for use in video compositing

### Tabs in GUI

1. **Fisheye Input** - Shows loaded front and back fisheye images side by side
2. **360° Equirectangular** - Shows the combined 360° image (useful for verification)
3. **Fisheye Masks** - Shows generated front and back mask outputs
4. **360° Mask** - Shows the intermediate equirectangular mask
5. **Overlay** - Shows mask overlaid on 360° image with adjustable opacity
6. **Perspective Views** - Shows all extracted perspective views with detections

### Command Line (CLI)

```bash
# Process a single fisheye pair
python cli.py front_fisheye.jpg -o front_mask.png

# The tool will auto-detect the back fisheye image

# Batch process a folder
python cli.py --batch /path/to/fisheye/folder

# Fast mode (fewer views, smaller model)
python cli.py front_fisheye.jpg -o mask.png --preset fast

# Accurate mode (more views, larger model)  
python cli.py front_fisheye.jpg -o mask.png --preset accurate

# Custom settings
python cli.py front_fisheye.jpg --views 12 --model yolo11m-seg.pt --confidence 0.3

# Verbose output
python cli.py front_fisheye.jpg -v
```

### Python API

```python
from core.pipeline import FisheyeMaskGenerationPipeline, PipelineConfig
from core.fisheye_converter import find_fisheye_pair, get_mask_output_paths
import cv2

# Create pipeline with default settings
pipeline = FisheyeMaskGenerationPipeline()

# Or customize configuration
config = PipelineConfig(
    num_horizontal_views=8,      # Number of views around horizon
    num_pitch_levels=2,          # Include up/down views
    fov=90.0,                    # Field of view per perspective
    model_name="yolo11l-seg.pt", # YOLO model to use
    target_classes=['person', 'backpack', 'handbag', 'suitcase'],
    confidence_threshold=0.35,   # Detection confidence
    dilate_mask=True,            # Expand mask slightly
    feather_edges=True           # Soft mask edges
)
pipeline = FisheyeMaskGenerationPipeline(config)

# Load fisheye pair
front_path = "frame0001_fisheye_front.jpg"
back_path = find_fisheye_pair(front_path)  # Auto-find matching back image

front_image = cv2.imread(front_path)
back_image = cv2.imread(back_path)

# Process the pair
result = pipeline.process(front_image, back_image)

# Save masks
front_mask_path, back_mask_path = get_mask_output_paths(front_path, back_path)
result.save_masks(front_mask_path, back_mask_path)

# Access intermediate results
print(f"Processing time: {result.processing_time:.1f}s")
print(f"Front mask coverage: {(result.front_mask > 0.5).mean() * 100:.1f}%")
print(f"Back mask coverage: {(result.back_mask > 0.5).mean() * 100:.1f}%")
```

### Batch Processing

```python
from core.pipeline import FisheyeBatchProcessor, PipelineConfig

config = PipelineConfig(
    model_name="yolo11l-seg.pt",
    target_classes=['person', 'backpack', 'handbag', 'suitcase'],
)

# Process all fisheye pairs in a folder
processor = FisheyeBatchProcessor(config, num_workers=1)  # GPU: 1 worker
summary = processor.process_folder("/path/to/fisheye/frames")

print(f"Processed {summary['successful']}/{summary['total']} pairs")
print(f"Total time: {summary['total_time']:.1f}s")
```

## Configuration Options

### View Settings

| Option | Description | Default |
|--------|-------------|---------|
| `num_horizontal_views` | Number of views around the horizon | 6 |
| `num_pitch_levels` | Vertical view levels (1=horizon, 2=up/down) | 2 |
| `fov` | Field of view per perspective (degrees) | 90° |
| `view_size` | Resolution of each perspective view | (1024, 1024) |
| `include_downward_view` | Add extra downward-facing view | False |
| `mask_upscale_factor` | Upscale masks before stitching (1, 2, 4) | 2 |

### Detection Settings

| Option | Description | Default |
|--------|-------------|---------|
| `model_name` | YOLO model to use | yolo11l-seg.pt |
| `target_classes` | Object classes to detect | person, backpack, handbag, suitcase |
| `confidence_threshold` | Minimum detection confidence | 0.35 |

### Post-Processing

| Option | Description | Default |
|--------|-------------|---------|
| `dilate_mask` | Expand mask edges | True |
| `dilation_iterations` | Number of dilation iterations | 2 |
| `feather_edges` | Apply Gaussian blur to mask edges | True |
| `feather_amount` | Feathering blur radius | 10 |

## YOLO Models

Available segmentation models (larger = more accurate but slower):

| Model | Size | Speed | Accuracy |
|-------|------|-------|----------|
| yolo11n-seg.pt | Nano | Fastest | Basic |
| yolo11s-seg.pt | Small | Fast | Good |
| yolo11m-seg.pt | Medium | Moderate | Better |
| yolo11l-seg.pt | Large | Slower | Best |
| yolo11x-seg.pt | XLarge | Slowest | Highest |

## Fisheye Projection Details

The tool assumes 185° FOV equidistant projection fisheye images:
- Front fisheye: Covers +Y hemisphere (forward-facing)
- Back fisheye: Covers -Y hemisphere (backward-facing)
- Combined coverage: Full 360° sphere with ~5° overlap

The conversion uses cached lookup tables for efficient processing.
